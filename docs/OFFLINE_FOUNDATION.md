# Offline Foundation

This document outlines the first bounded offline phase of the Huginn & Muninn project. The phase will establish a standard-library deterministic portfolio snapshot/accounting and coverage domain with synthetic fixtures only. Decimal arithmetic, explicit currency/as-of/provenance, and approved externally supplied conversion inputs will be used. Missing/unknown values will never silently zero or omitted, and valuation/exposure/analytical coverage will be separate and unbounded unknowns explicitly reported. Unsupported holdings will be preserved visibly. No percentage advice, optimization, tax engine certification, return assumptions, forecast skill claims, personalized policy defaults, or tactical activation will be included. No FastAPI/PostgreSQL/React runtime provisioning, data vendor/broker/API connections, purchases, private financial imports, services/deployment, or merge/push will be allowed in this phase.
